# Energy Detective｜Executive Summary

**研究定位：**Energy Detective 是一套面向一般家庭的用電分析與節能決策 AI Agent 研究提案，目的是讓使用者以自然語言查詢歷史用電、比較不同時段、辨識值得檢查的異常候選、取得下一小時預測，並接收有來源及適用限制的檢查建議。研究重點不是聲稱能直接節電，而是建立「計算可核對、證據可追溯、資料不足不過度推論」的可信賴回答流程。

**研究方法：**初版規劃使用 UCI Individual Household Electric Power Consumption 單戶分鐘級歷史資料，依固定回放時點建立唯讀資料視圖。以功率與電量正確換算、時間格網與缺值完整性檢查做為所有分析工具的共同契約。單一雲端 LLM Agent 負責意圖解析、工具調度與提出澄清，固定分析工具執行查詢、期間比較、同時刻與日型的 MAD 異常候選標記及 Random Forest 下一小時負載預測。能源知識庫以具來源的小型規則集限制過度推論；證據紀錄及回覆驗證則核對數字、日期、單位、增減方向與引用結果。預計使用 Streamlit 呈現趨勢、摘要、證據與限制。

**實驗設計：**預測部分依時間順序切分資料，以 Persistence 及 Daily Seasonal Naive 為基準，報告 MAE、RMSE 與可用率。Agent部分先試測10題，再以50題正式題集比較有無外部回答驗證及一次修正的差異，每個條件各重複三次，共計畫300次任務執行；評估任務完成、數值與時間正確性、證據一致性、適當澄清、建議可行性及時間與模型成本。合成異常測試須與真實故障辨識嚴格區隔。

**研究價值與限制：**預期形成可重現的家庭用電 Agent 設計、明確的工具／資料契約及可靠性評估紀錄，釐清外部驗證能否改善回答與其成本代價。目前 GitHub 提供研究文件與提案草稿，尚無可運作的 App、模型訓練、正式實驗或節電成效。法國單戶舊資料亦不能直接代表台灣家庭、獨立電器或實際費率。
