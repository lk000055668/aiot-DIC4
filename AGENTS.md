# DIC4 — ICEIB Conference Paper

## Paper goal

- Write an academic paper in English for ICEIB using the IEEE conference
  template specified for the submission.
- Include these sections in order: Abstract, Introduction, Related Work,
  Proposed Design, Experiments, Conclusion, and References.
- Follow the A-to-Z writing guide provided by the instructor.
  If the guide is unavailable, ask for it before drafting content that
  depends on its requirements.
- Use verified sources for citations and actual results for experimental
  claims. Mark missing evidence and unfinished experiments as pending.

## OpenSpec workflow

- Use OpenSpec to plan the initial paper and major revisions.
- If a relevant change already exists, continue it. Otherwise, create a
  change such as `draft-iceib-paper`.
- Record the scope and rationale in `proposal.md`, acceptance criteria in
  `specs/`, and section-level writing and review tasks in `tasks.md`.
- Mark a task complete after checking the corresponding acceptance criteria.

## Overleaf workflow

- Use the `overleaf` MCP server for the paper.
  Project: <DIC4>.
- Inspect the existing LaTeX source and bibliography before editing.
- After editing, compile the paper and report any unresolved errors,
  missing citations, or placeholder results.
